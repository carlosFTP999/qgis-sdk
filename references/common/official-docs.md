# Official Documentation

Official upstream documentation for QGIS plugin work, grouped by component.
Prefer these sources over community posts when behavior, API, or metadata
requirements are in question.

## QGIS docs and PyQGIS

- QGIS documentation: https://docs.qgis.org/
- PyQGIS developer cookbook (QGIS 3.44): https://docs.qgis.org/3.44/en/docs/pyqgis_developer_cookbook/
- PyQGIS developer cookbook (QGIS 3.40): https://docs.qgis.org/3.40/en/docs/pyqgis_developer_cookbook/
- Plugin `metadata.txt` reference: https://docs.qgis.org/3.44/en/docs/pyqgis_developer_cookbook/plugins/plugins.html#metadata-txt
- Releasing plugins: https://docs.qgis.org/3.40/en/docs/pyqgis_developer_cookbook/plugins/releasing.html
- Geometry handling: https://docs.qgis.org/3.40/en/docs/pyqgis_developer_cookbook/geometry.html
- PyQGIS API reference: https://qgis.org/pyqgis/
- `QgsGeometry` (3.44): https://qgis.org/pyqgis/3.44/core/QgsGeometry.html
- `Qgis` (master): https://qgis.org/pyqgis/master/core/Qgis.html
- `QgsWkbTypes` (master): https://qgis.org/pyqgis/master/core/QgsWkbTypes.html
